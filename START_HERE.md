# SparkStack — start here (you are learning, this is written for you)

This is a **real starter app** you can open in a browser on your phone. It does not cost money to try.

It is **not** on Google Play yet. It does **not** pay real Bitcoin yet. That is on purpose so you do not spend money and so we stay honest.

## What it does today
- Daily check-in → points
- Demo “watch ad” and “offers” buttons (practice only)
- 3 short lessons (you earn points for the right answer)
- Paste **your** public wallet address (view only)
- Live BTC / ETH / SOL prices from CoinGecko (needs internet)

Points live only in **this browser**. Clear site data = points gone. That is fine for learning.

## How to open it
1. Keep the `sparkstack` folder on your computer or phone.
2. Open `index.html` in Chrome or Safari.
3. On a phone: Chrome menu → **Add to Home screen**.

To put it on the internet for free, follow **HOSTING.md** (Netlify or GitHub Pages). English only.

## What you do next (no rush)
1. Use the app for a few days so you understand the screens.
2. Make a wallet in a well-known app. Write the seed on paper. Never put the seed in SparkStack.
3. Paste only the receive address on the Wallet tab.
4. When you want Google Play: you need Google’s **US$25** developer fee. I can help turn this into an Android project then.
5. When you want real ads: create a free **AdMob** account. I can show where the demo ad button is replaced.
